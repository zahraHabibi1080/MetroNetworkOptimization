# بهینه‌سازی مسیر مترو با الگوریتم مورچگان (ACO)

این پروژه با استفاده از الگوریتم **Ant Colony Optimization**، کوتاه‌ترین مسیر بین ایستگاه‌های مترو را پیدا می‌کند.

## ویژگی‌ها:
- پردازش خودکار داده‌های اکسل
- مدل‌سازی گراف شبکه مترو
- قابلیت پیدا کردن مسیر در ایستگاه‌های تقاطعی (تعویض خط)
- نمایش مسیر با نام ایستگاه‌ها و محاسبه دقیق فاصله

## نحوه اجرا:
1. کتابخانه‌های مورد نیاز را نصب کنید:
   `pip install -r requirements.txt`
2. فایل `main.py` را اجرا کنید.
